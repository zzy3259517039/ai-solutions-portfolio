# AI 解决方案与业务自动化作品集

面向 **AI 实施、AI 解决方案、初级 FDE** 岗位的精选实践。围绕知识库客服、会议任务交付、更新通知与交易流程，展示从业务规则到可检查结果的过程。

**实现方式：使用 Codex 等 AI 工具辅助开发。** 代码、配置和资料的完成状态与本人独立理解、排障、真实客户交付能力分别评价。这里的演示业务和样例数据是虚构的；不声称已有付费客户、生产部署或收益。

## 五分钟浏览顺序

1. 看 [景区案例与验收记录](projects/scenic-rag/README.md)：为什么不能把答案直接写死在提示词里，知识更新后如何验证。
2. 看 [会议 Skill](skills/meeting-delivery/README.md)：如何防止 AI 把建议变成执行任务、猜负责人和日期。
3. 看 [通知状态机](projects/bilibili-monitor/README.md)：超时后为什么不能盲目重发。
4. 按需查看团购演示与微信集成原型，确认演示、接口实现和真实平台验收之间的区别。

## 本地快速检查

需要 Node.js 22+；B 站项目另需 Windows + Python 3.11+。各项目独立运行，无需统一安装大环境。

```bash
node --test skills/meeting-delivery/tests/*.test.mjs
cd projects/fruit-groupbuy-demo
npm test
npm start
```

浏览器访问 `http://127.0.0.1:8766` 体验团购。会议 Skill 的样例导出和 B 站测试命令见各项目 README。微信实验室需要安装其 npm 依赖；数据库集成检查另需隔离的 MySQL 环境。
