# 售后问答的 source 为什么会为空

## 问题与证据

用户在现有售后规则工作流中提出：回答“签收商品后多久可以申请无理由退货”时，来源必须是“规则一：七天无理由退货”；规则外问题才可留空，并交给人工。

2026-10-12 检查开发记录，可见修复版本 `ee30727` 的解释。以下根因与修复措施来自该开发摘要，**本轮没有独立检查知识库分块或复测云端结果**。

## 开发记录中的排查过程

1. 原资料按换行切分，规则标题与正文可能落入不同片段。正文召回后，回答节点仍拿不到标题。
2. 按空行重新切分，将标题和正文作为完整规则块，导入 `after_sales_rules_v2`。
3. 检索节点提取标题，并以“来源规则：{标题}”形式传给回答节点。
4. 回答配置要求有可靠依据时输出命中的标题；无依据才留空并转人工。

这体现了一个可迁移的排障方法：先检查资料、分块和召回，再检查节点传参，最后检查输出解析。仅加强“必须带来源”的提示词，无法补回输入中缺失的标题。

## 下一次怎样验收

检查导入后的每个块确实携带标题；记录检索分数、原文片段、传给回答节点的上下文以及最终三字段。分别复测规则内、规则外与相近规则问题，核对回答条件和来源是否匹配。记录版本、日期和原始结果，再比较修复前后。

检索阈值与 top_k 只是配置参数，不是“可靠”的业务证明。标题非空也不等于引用正确；不同店铺政策、过期规则和异常投诉仍需要人工判断。
